# All Access Website

Customer Experience & Communication Outsourcing.

## Stack
- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Lucide React + React Icons

## Setup
```bash
npm install
npm run dev
```

## Features
- Transparent logo on white navbar & footer
- Hero with team photography
- Service cards with icons
- Inquiry modal ("Get started") for Support / Booking / Partnership / General
- About page with timeline + team members
- Contact with social icons
- Partners section
- Smooth scroll animations
- Fully responsive
